# BinaryBoss

A browser-based binary-to-decimal game built with HTML, CSS, and JavaScript.

## Play

Open `index.html` in a browser, enter a nickname, and convert each 8-bit signal to decimal. Every correct answer adds 10 points. The leaderboard keeps each nickname's best score in this browser's `localStorage`.

Scores are not shared with other people, browsers, or devices. A shared online leaderboard requires a backend and database.
